ℹ️ About QRShield

A web-based pre-click link and QR code risk analyzer with explainable threat indicators.

🚫

What it does not do

  • It never opens, fetches or follows the submitted URL.
  • It cannot prove a link is safe. A low score means few heuristics fired.
  • HTTPS does not prove a website is legitimate.
🔒

Privacy

Stored URLs have credentials and fragments removed, query values replaced with [redacted] and token-like path segments masked. Uploaded QR images are deleted immediately after processing. Records stay until you clear history.

⚠️

Limits of this version

This is a local single-user app with no login: anyone who can open the site can read its history. Add authentication before any multi-user deployment. If you enable the optional Google Safe Browsing integration, the URL string is sent to Google.

⚙️

Tech Stack

  • Java 17 · Spring Boot 3.3.5
  • Thymeleaf · Bootstrap 5 (dark)
  • SQLite · Spring JDBC
  • Google ZXing (QR decoding)
  • Google Safe Browsing v4 (optional)
